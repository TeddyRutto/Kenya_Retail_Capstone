# Kenya_Retail_Capstone
# Customer and Sales Intelligence for a Kenyan Retailer

Individual data science and analytics capstone. This project turns retail
sales and customer data into evidence a manager can act on.

## Business questions
1. Which products and stores drive the most revenue, and how does this vary by county?
2. Which customers are drifting away (churn)?
3. Did promotions lift sales?
4. What demand should we expect next month?

*(To be refined in Milestone 1.)*
